# 🌸 Community Code of Conduct

Hey! Welcome to the **Isekai Tab** community.

This is an open source passion project built by a solo developer for people who love anime, Linux ricing, and clean desktop aesthetics. We want this project to be friendly, welcoming, and relaxed for everyone.

---

## Rules

1. **Be kind and respectful**
   Treat others the way you would like to be treated. Whether someone is a seasoned software engineer or someone opening their very first pull request, treat them with patience and encouragement.

2. **No toxic behavior or gatekeeping**
   Hate speech, personal attacks, harassment, or elitist gatekeeping will not be tolerated. Keep discussions polite and focused on building great software.

3. **Constructive and thoughtful feedback**
   If you disagree with an architectural decision, UI choice, or an idea, critique the implementation—never the person. Offer practical solutions and alternatives.

4. **Help each other out**
   Found a bug? Have an idea? Open an issue or join the discussion. If you see someone needing help with setup, feel free to pitch in!

---

## 🎐 Handling Issues

If someone is being disrespectful, harassing others, or making the space uncomfortable, please report it directly to the repository maintainer ([@urstark](https://github.com/urstark)). We will look into it promptly and take appropriate action.

Let's keep things chill, respectful, and fun! 🌸✨
